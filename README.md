# Game Dev+ Club Website

A multi-page gaming club website created using HTML, CSS, and JavaScript.

This project represents the fictional "Game Dev+ Club" of VIT Pune

---

## Features

- Multi-page website
- Navigation bar across pages
- Gaming-themed UI
- Image and video integration
- Club team details table
- Responsive structured layout
- Footer with social and quick links

---

## Pages Included

- Home
- About
- Events
- Gallery
- Achievements
- Join Us
- Contact

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
